# Промпт для генерации дайджеста

Используй этот промпт каждую неделю. Дай Claude ссылку на выпуск JavaScript Weekly и вставь этот текст.

---

## Инструкция для Claude

Ты помогаешь мне (Иван Осипов, Senior Frontend Engineer) готовить еженедельный дайджест для моего сайта ivanosipov.dev.

**Задача:** прочитай выпуск JavaScript Weekly по ссылке, выбери 5 самых интересных материалов и сгенерируй готовый markdown-файл для публикации.

**Критерии отбора статей:**
- Практическая польза для middle/senior frontend разработчиков
- Актуальность: новые релизы, важные изменения в экосистеме
- Глубина: предпочитай детальные разборы поверхностным обзорам
- Разнообразие: не бери 5 статей об одном и том же

**Формат каждого элемента:**
```
## [Заголовок статьи на русском](оригинальная ссылка)

2-3 предложения: о чём статья, что там внутри, почему это важно. Без воды.

> Моя рекомендация: 1-2 предложения от первого лица — личный взгляд, кому особенно полезно, на что обратить внимание.

---
```

**Правила для рекомендации:**
- Пиши от первого лица ("я", "рекомендую", "стоит")
- Конкретно: для кого полезно, в каком контексте применить
- Без дежурных фраз вроде "отличная статья" или "настоятельно рекомендую"

**Формат итогового файла:**

Имя файла: `YYYY-wNN.md` (год и номер недели, например `2025-w17.md`)

```markdown
---
title: "JS Дайджест #N"
issue: [номер выпуска JS Weekly]
date: "YYYY-MM-DD"
source: "https://javascriptweekly.com/issues/[номер]"
---

[5 статей в формате выше]
```

Номер дайджеста (#N) — порядковый, начиная с #1. Я скажу текущий номер.

---

## Как использовать

1. Открой новый чат с Claude
2. Вставь этот промпт
3. Добавь: "Вот ссылка на выпуск: [ссылка]. Это дайджест #[номер]."
4. Получи готовый файл, положи его в `src/content/digest/`
5. Задеплой
